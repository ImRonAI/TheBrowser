# Methodology Design Rubric

## Query Engineering Standards
- Pair broad semantic queries with high-precision lexical queries (exact identifiers, RFC/paper titles, dataset names).
- Specify freshness bounds (`pd`, `pw`, `pm`, `py`, or unbounded archival) per sub-question based on whether recency or foundational accuracy governs.
- Define measurable completion criteria per sub-question (minimum independent corroborating sources).
