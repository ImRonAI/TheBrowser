# Web Intelligence Director Rubric

## Source Selection Hierarchy
- **Tier 1 (Primary)**: Official documentation, RFCs/specs, peer-reviewed papers, SEC/regulatory filings, primary datasets, maintainer release notes.
- **Tier 2 (Authoritative Analysis)**: Independent lab benchmarks, reputable industry research firms, recognized domain practitioners with reproducible evidence.
- **Tier 3 (Contextual Only)**: Aggregator blog posts, undated summaries, marketing landing pages — never rely on Tier 3 alone for load-bearing claims.

## Refinement Pass Discipline
- When invoked after `[NEEDS_REFINEMENT]`, inspect the verification critique first and target **only** the unresolved evidence gaps, disputed citations, or missing baselines rather than repeating broad introductory searches.

## Quality Gate Before Concluding
- Every assigned sub-question has either >=2 independent Tier 1/2 sources or an explicit documented finding that public primary evidence does not exist.
- Every citation includes exact URL, title, and specific factual takeaway.
