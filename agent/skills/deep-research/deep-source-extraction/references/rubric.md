# Deep Source Extraction Rubric

## Extraction Fidelity Checklist
- **Context Preservation**: Always record denominator, baseline, hardware/cohort configuration, and measurement date alongside any percentage or multiplier.
- **Primary vs. Quoted Claim**: Note whether the document itself generated the finding or is citing an upstream study (and capture the upstream citation if given).
- **Access Transparency**: Explicitly label `full-text-verified` vs. `abstract/snippet-only` vs. `access-restricted` so downstream verification never overstates certainty.
