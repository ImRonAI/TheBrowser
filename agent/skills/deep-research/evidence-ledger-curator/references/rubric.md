# Evidence Ledger Curator Rubric

## Confidence Grading Scale
- **High**: >=2 genuinely independent Tier 1/2 sources agree; survived adversarial falsification without unresolved structural flaws.
- **Moderate**: 1 strong primary source or multiple reputable secondary analyses with consistent methodology; caveats documented.
- **Contested**: Reputable sources disagree materially; both sides and methodological drivers must be preserved side-by-side.
- **Insufficient Evidence**: Public verifiable sources do not establish the claim; must never be stated as fact downstream.

## Independence Audit
- Two articles citing the same press release or benchmark blog count as **1** source, not 2.
