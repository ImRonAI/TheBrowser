# Source Verification Rubric

## Zero-Tolerance Audit Checks
- **Exact Numeric Match**: Check order of magnitude, currency/unit, and whether a number is historical actual vs. forecast.
- **Negation / Conditional Flip**: Confirm the source did not state a hypothesis or counterfactual that was mistakenly recorded as an established outcome.
- **Canonical URL Hygiene**: Strip tracking query parameters when reporting verified canonical URLs while keeping exact path integrity.
