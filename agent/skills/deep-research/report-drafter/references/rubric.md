# Report Drafter Rubric

## Structural Blueprint
1. **Title (`# ...`)** & **Executive Summary** (direct answer first, key takeaways, confidence level).
2. **Deep-Dive Analytical Sections** mapped to core dimensions/sub-questions, incorporating Markdown comparison tables where quantitative trade-offs exist.
3. **Contested Evidence, Risks & Boundary Conditions** preserving adversarial insights honestly.
4. **Actionable Implications / Decision Matrix** tailored to user context.
5. **Sources** (`## Sources`) listing canonical verified `[Title](URL)` references.

## Fidelity Rule
- Drop any claim quarantined by `verification_swarm`; never resurrect unverified assertions for narrative smoothness.
