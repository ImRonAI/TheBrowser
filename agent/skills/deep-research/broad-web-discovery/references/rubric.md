# Broad Web Discovery Rubric

## Query Diversity Rules
- **Terminology Variation**: Pair practitioner jargon with formal academic/regulatory terminology.
- **Disconfirmation Angle**: Include at least one query targeting limitations, trade-offs, or post-mortems rather than purely promotional phrasing.
- **Deduplication**: Collapse syndications/mirrors of the same press release into a single canonical origin URL.

## Output Standards
- Never fabricate URLs or extrapolate beyond search snippets; flag promising URLs whose full data tables or methodology require `deep-source-extraction`.
