# News & Quantitative Data Director Rubric

## Temporal Hygiene
- Anchor every event to an explicit ISO date (`YYYY-MM-DD` or `YYYY-MM`) whenever available; flag undated articles explicitly.
- Detect when older widely-cited figures have been superseded by newer releases, errata, or revised filings.

## Quantitative Rigor
- Never merge incompatible metrics (e.g., ARR vs. run-rate revenue, synthetic microbenchmark vs. production p99 latency, list price vs. realized cost).
- Preserve error bars, ranges, and discrepancy explanations when two reputable sources report different numbers.
