# Executive Editor Rubric

## Publication Gate Checklist
- **Answer-First Opening**: `## Executive Summary` directly answers the user's question in the first paragraph before elaborating nuances.
- **Zero Process Leakage**: Strip internal orchestration terminology (`Evidence Ledger`, `adversarial_swarm`, `[VERIFICATION_PASSED]`, `Q1/Q2` scaffolding labels unless helpful).
- **Intact Citations**: Every `[Title](https://...)` link from `report_drafter` remains clickable and intact; valid GFM tables render cleanly without broken pipes.
